# MarketPlace

A Jumia-style online marketplace where sellers list products and buyers browse and shop.

**Live demo:** https://lhelnaldo123-hub.github.io/Marketplace/

## Features
- Browse products as a guest, then sign up to buy
- Sign up and log in with Google or email and password
- Admin page for managing sellers and uploading products
- Installable on a phone as a web app (PWA)
- Mobile-friendly design

## Built with
- HTML, CSS and JavaScript
- Firebase (authentication and database)
- GitHub Pages hosting

## Files
- `index.html` - main marketplace app
- `admin.html` - admin page
- `SW.js` and `manifest.json` - installable app and offline support
